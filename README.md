## ✨ Features & Highlights

- 🚀 **2.5D Hybrid WebGL Perspective**: Calibrated $48^\circ$ perspective camera tilted at $60^\circ$, granting deep visual immersion without sacrificing classic 2D bullet hell hitbox precision.
- 🛩️ **Procedural Low-Poly Aircraft Models**:
  - **Player Spitfire/Mustang**: Swept dihedral wings, cyan leading-edge neon conduits, glass bubble canopy, pulsing wingtip plasma blasters, twin cyan wingtip trails, and throttle-pulsed exhaust plumes.
  - **Dynamic Roll Banking**: Real-time aerodynamic flight roll kinematics coupled to mouse/touch drag velocity.
  - **Holographic Energy Shield**: Geodesic rotating wireframe shell protecting against flak and collision.
  - **Hostile Fleet & Boss Dreadnoughts**: Delta-wing dive bombers with glowing visors and giant multi-engine flying fortresses with pulsating red radioactive core reactors.
- 💥 **Explosive Visual Juice & Particle FX**:
  - Golden 3D plasma energy bolts and glowing enemy spheres.
  - Low-poly kinetic debris fracturing (tumbling 3D hull fragments with velocity, drag, and gravity).
  - Expanding 3D radial shockwaves and screen trauma shake.
  - Infinite neon cyan scrolling cyber grid, wireframe data monoliths, and supersonic speed lines.
- 🏆 **Global Leaderboard & DDA**: Live cloud high-score sync via GitHub Gist and Dynamic Difficulty Adjustment.
- 🔊 **Procedural Web Audio Engine**: Zero-lag real-time sound synthesis for plasma guns, jet thrusters, and explosive detonations.
