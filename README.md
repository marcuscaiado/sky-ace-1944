## ✨ Features & Highlights

- ✈️ **Intense Bullet-Hell Aerial Warfare**: Dodge dense enemy bullet patterns with tight hitbox precision.
- 💣 **Screen-Clearing Mega Bombs**: Annihilate all hostile aircraft and projectiles in a blinding shockwave.
- ⚡ **Weapon Arsenal Upgrades**:
  - 🔫 **Dual & Quad Machine Guns**: High-velocity forward cannons.
  - 💥 **Spread Shot**: Wide-angle defensive firepower.
  - 🛡️ **Deflector Shield**: Absorbs incoming flak and direct collisions.
- 👾 **Epic Flagship Bosses**: Heavy dreadnoughts and giant flying fortresses with destructible turrets.
- 🔊 **Procedural Retro SFX**: Authentic propeller buzzes, machine gun fire, and massive explosion booms.

## 🕹️ Controls

| Action | Desktop / Keyboard / Mouse | Mobile / Touch |
| :--- | :--- | :--- |
| **Move Fighter** | `W, A, S, D` / Mouse Drag | Drag Finger across screen |
| **Fire Guns** | Auto-fire or Left-Click | Auto-fire |
| **Mega Bomb** | `[SPACEBAR]` or Right-Click | Tap **BOMB** Icon |
| **Pause** | `[ESC]` or `[P]` | Tap Pause Button |
